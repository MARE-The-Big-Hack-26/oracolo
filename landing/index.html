Blind-spot prediction in action.

ClearCorner estimates occluded pedestrian trajectories behind racks and caps forklift speed before a collision can occur.

ClearCorner · Open Source Prototype

Download or run in one command.

Works on macOS, Linux, and Windows (Python 3.9+). Includes the warehouse simulator, 135-test suite, and browser display for the forklift operator. For live camera tracking, also run pip install -r requirements-vision.txt (requires opencv-python-headless<5).

Download Source (.zip)

Downloaded the .zip? Extract it and open the oracolo-main/repo folder (git clone creates oracolo/repo).

git clone https://github.com/MARE-The-Big-Hack-26/oracolo.git && cd oracolo/repo && python3 -m pip install -r requirements.txt && PYTHONPATH=. python3 scripts/run_live.py --loop
  • Starts the local demo server and prints a URL (e.g. http://<your-ip>:8000).
  • Open that URL in any browser to see live speed limits and safety levels (L0–L3).
  • Ready when: the terminal prints Cabina pronta and the page updates in real time.
