Blind-spot prediction in action.

ClearCorner estimates occluded pedestrian trajectories behind racks and caps forklift speed before a collision can occur.

ClearCorner · Open Source Prototype

Download or run in one command.

Works on macOS, Linux, and Windows (Python 3.9+). Includes the warehouse simulator, 135-test suite, and browser display for the forklift operator. For live camera tracking, also run pip install -r requirements-vision.txt (requires opencv-python-headless<5).

Download Source (.zip)

Downloaded the .zip? Unzip oracolo-main.zip and double-click START.command (Mac) or START.bat (Windows) — the app opens automatically.

git clone https://github.com/MARE-The-Big-Hack-26/oracolo.git && python3 oracolo/start.py
  • 1. Run once: creates a local virtual environment and installs dependencies automatically.
  • 2. Opens automatically: your browser opens the live forklift display (L0–L3) as soon as it is ready.
  • 3. Full camera + 3D map panel: run pip install -r requirements-vision.txt inside repo/, then PYTHONPATH=. python3 scripts/run_camera.py --source cam:0 --http --no-tunnel.
